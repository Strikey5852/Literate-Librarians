# Literate Librarians

[![Modrinth](https://img.shields.io/badge/Modrinth-Available-00AF5C?logo=modrinth&logoColor=white)](https://modrinth.com/mod/literate-librarians)

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](LICENSE)

## Features

- Allows placing enchanted books on lecterns, and makes librarian villagers more likely to trade the enchanted book on their lectern.

## Config

- `overrideChance` (0.0–1.0) - chance the lectern trade override applies.
- `enableNonTradeableEnchants` (true/false) - allows the mod to work for books villagers don't trade (e.g. Swift Sneak, Soul Speed).
